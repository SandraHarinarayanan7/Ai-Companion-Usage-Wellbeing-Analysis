# AI Companion Usage & Wellbeing Insights – Power BI

## 📌 Project Overview

This project analyzes patterns in AI companion usage and their relationship with wellbeing, social interaction, sleep quality, and academic or work performance. The interactive Power BI dashboard transforms user-level data into meaningful insights around AI usage behavior, emotional attachment, loneliness, social connections, and dependency patterns.

The project involved data cleaning, data transformation, column creation, and exploratory analysis before developing the final dashboard. Power BI was used to create interactive visualizations and key performance indicators that make complex behavioral patterns easier to understand and interpret.

## 🎯 Objectives

- Analyze AI usage patterns across different user groups
  
- Examine the relationship between AI usage and wellbeing indicators
  
- Explore patterns of loneliness and emotional attachment
  
- Analyze AI usage in relation to social interaction and screen time
  
- Examine sleep quality and its association with AI usage
  
- Understand AI dependency risk patterns
  
- Evaluate the relationship between AI usage and academic or work performance
  
- Present key findings through an interactive Power BI dashboard

## 🧹 Data Preparation

The dataset was cleaned and prepared before being used for analysis. The preparation process included reviewing data quality, handling inconsistencies, transforming fields, and creating additional columns required for meaningful analysis and visualization.

The prepared dataset was then used to develop calculated metrics, KPIs, categories, and interactive visualizations in Power BI.

## 📊 Dashboard Highlights

The dashboard provides insights into:

- Total Number of Users
  
- Average Daily AI Chat Hours
  
- Average Human Interaction Hours
  
- Average Sleep Quality Score
  
- AI Dependency Risk Distribution
  
- Loneliness and Emotional Attachment Patterns
  
- AI Usage and Screen Time Across Academic/Work Performance
  
- Sleep Quality and Screen Time Patterns
  
- AI Chat Hours and Loneliness
  
- AI Chat Hours and Screen Time by Platform

## 💡 Key Insights

The dashboard provides an interactive view of how AI companion usage varies across users and how it relates to factors such as loneliness, emotional attachment, social interaction, sleep quality, screen time, and academic or work performance.

It also highlights different levels of AI dependency risk, allowing patterns in user behavior and wellbeing indicators to be explored across multiple dimensions.

## 🏁 Conclusion

This project demonstrates the application of data cleaning, transformation, analysis, and visualization techniques to explore AI companion usage and its relationship with behavioral and wellbeing indicators.

The interactive Power BI dashboard presents complex user-level data through clear KPIs and visualizations, enabling patterns and relationships to be explored effectively.
